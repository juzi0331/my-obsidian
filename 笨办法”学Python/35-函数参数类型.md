# 🐍 Python 进阶：函数作为参数传递

> [!ABSTRACT]  Python 进阶：函数作为参数传递
在 Python 中，函数被视为“一等公民”。这意味着函数不仅可以被调用，还可以像普通变量一样被传递、赋值或作为参数。

### 1. 参数类型的分类

函数接收的参数可以分为以下两类：

- **普通参数**：包括数字（int/float）、布尔值（bool）、字符串（str）、列表（list）、元组（tuple）、集合（set）以及字典（dict）等数据类型。
- **特殊类型**：**函数 (Function)**。你可以将一个函数的名称作为实参传递给另一个函数。

### 2. 高阶函数实战：逻辑抽象

当一个函数接收另一个函数作为参数时，我们称之为**高阶函数**。这种模式允许我们将“计算逻辑”本身动态化。

#### 🔹 代码逻辑

在代码中，`calc` 函数并不关心具体的运算规则，它只负责调用传入的 `oper`：

1. **定义基础运算**：
    - `add(x, y)`：返回 $x + y$。
    - `subtract(x, y)`：返回 $x - y$。
2. **定义通用计算器**：
    - `calc(x, y, oper)`：接收两个数值和一个运算函数 `oper`。
3. **动态调用**：
    - 执行 `calc(10, 20, add)` 时，`add` 函数被传递进去，最终执行加法。

```Python
# 定义计算逻辑
def add(x, y):
    return x + y

def subtract(x, y):
    return x - y

# 高阶函数：oper 参数接收的是一个函数
def calc(x, y, oper):
    return oper(x, y) # 在此处执行传入的逻辑

# 调用示例
result = calc(10, 20, add) # 传入 add 函数
print(result) # 输出: 30
```

|**维度**|**传统方式**|**函数参数方式**|
|---|---|---|
|**灵活性**|逻辑固定在函数内部|逻辑由调用者动态决定|
|**解耦程度**|低（改算法需改函数）|高（算法与框架分离）|
|**代码复用**|需编写多个类似的计算函数|只需一个通用模板函数|

### 💡 核心总结

1. **传递的是引用**：传递函数参数时，只需写函数名（如 `add`），不要带括号（如 `add()`），带括号表示立即执行该函数并传递其返回值。
2. **逻辑解耦**：通过这种方式，`calc` 函数只负责“何时执行”，而具体的“执行什么”交给了外部传入的 `add` 或 `subtract`。
3. **扩展性**：未来如果你想增加“乘法”，只需定义一个 `multiply` 函数并传给 `calc`，而不需要修改 `calc` 函数的代码。
