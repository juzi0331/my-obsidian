# 🐍 Python 进阶：函数不定长参数

> [!ABSTRACT]  Python 进阶：函数不定长参数
不定长参数适用于参数个数不确定（0 个或多个）的场景。Python 提供了两种主要的传递方式：**位置传递**与**关键字传递**。

### 1. 位置不定长参数 (`*args`)

当你在参数名前加上一个星号 `*` 时，Python 会收集所有匹配的位置参数并将其封装成一个**元组 (Tuple)**。

- **核心特性**：`args` 是元组类型，仅收集位置参数，不收集关键字参数。
- **命名约定**：`args` 只是约定俗成的变量名，你可以使用任何合法的变量名（如 `*data`）。
- **数学应用示例：** 计算传入数值的平均值：$avg\_data = \sum args / len(args)$。


### 2. 关键字不定长参数 (`**kwargs`)

当你在参数名前加上两个星号 `**` 时，Python 会收集所有“键=值”形式的参数并将其封装成一个**字典 (Dict)**。

- **核心特性**：以 `key=value` 形式传递，`kwargs` 接受后合并为字典。
- **命名约定**：`kwargs` 也是惯例名称，可自定义为 `**options` 等。


### 3. 综合实战：多功能数据计算器

通过混合使用 `*args` 和 `**kwargs`，我们可以编写一个既能处理任意数量数值，又能通过关键字控制输出格式的强大函数。

```Python
# 定义函数：同时接收不定长位置参数和关键字参数
def calc_data(*args, **kwargs):
    min_data = min(args)    # 获取最小值
    max_data = max(args)    # 获取最大值
    avg_data = sum(args) / len(args) # 计算平均值

    # 从 kwargs 字典中安全获取配置信息
    if kwargs.get("round") is not None:
        avg_data = round(avg_data, kwargs.get("round")) # 按需保留小数

    if kwargs.get("print"):
        print(f"最小值: {min_data}, 最大值: {max_data}, 平均值: {avg_data}")

    return min_data, max_data, avg_data

# 调用示例：传入 5 个数字，并指定保留 3 位小数及开启打印
result = calc_data(10, 20, 30, 40, 50, round=3, print=True)
```

|**参数类型**|**语法标识**|**封装类型**|**接收场景**|
|---|---|---|---|
|**位置不定长**|`*args`|**元组 (Tuple)**|接收 0 或多个纯数值/对象|
|**关键字不定长**|`**kwargs`|**字典 (Dict)**|接收带有标签的配置或属性|
### 💡 核心注意点

1. **参数顺序**：在函数定义中，如果混合使用多种参数，通常顺序为：**普通参数 > `*args` > 默认参数 > `**kwargs`**。
2. **解包功能**：除了在定义时“打包”参数，`*` 和 `**` 也可以在调用函数时用于将现有的列表或字典“解包”后传递。
3. **灵活性**：这在编写装饰器或转发参数的函数时非常有用，因为它允许函数透传任何它收到的输入
